# AI-Based Customer Sentiment Analysis

## 📌 Project Overview

AI-Based Customer Sentiment Analysis is a Natural Language Processing (NLP) and Machine Learning project that analyzes customer reviews and classifies them into three sentiment categories:

* **Positive**
* **Neutral**
* **Negative**

The project uses **TF-IDF** for converting text reviews into numerical features and **Logistic Regression** for sentiment classification.

The project is developed using **Python** and can be executed easily in **Google Colab**.

---

## 🎯 Objective

The main objective of this project is to automatically understand the sentiment expressed in customer reviews.

This system can help businesses identify whether customers are satisfied, neutral, or dissatisfied with their products or services.

## 📊 Dataset

The project uses a small sample customer-review dataset created for demonstration and educational purposes.

The dataset contains:

* **30 customer reviews**
* **10 Positive reviews**
* **10 Neutral reviews**
* **10 Negative reviews**

### Dataset Columns

| Column      | Description          |
| ----------- | -------------------- |
| `review`    | Customer review text |
| `sentiment` | Sentiment category   |

---

## 🤖 Machine Learning Algorithm

### Logistic Regression

Logistic Regression is used to classify customer reviews into the three sentiment categories.

The text is first converted into numerical features using **TF-IDF**, and these features are then provided to the Logistic Regression classifier.
